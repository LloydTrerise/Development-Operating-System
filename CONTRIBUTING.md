# Contributing to DevOS

## Development Process

DevOS follows a specification-driven development process.

Every implementation task should follow:

1. Understand the specification
2. Analyse the existing system
3. Produce an implementation plan
4. Obtain approval where required
5. Implement
6. Test
7. Validate against the specification
8. Review
9. Merge

## Task Identification

Implementation tasks use the format:

`DEVOS-XXX`

Example:

`DEVOS-001`

## Scope

Developers and AI coding agents must not silently expand the scope
of an implementation task.

If a specification is incomplete or contradictory, raise the issue
before implementation.

## Testing

All applicable tests must pass before a task is considered complete.

## Security

Security controls must be implemented at the application/platform
level and must never depend solely on AI behaviour.
