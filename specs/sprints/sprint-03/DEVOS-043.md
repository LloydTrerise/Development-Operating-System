# DEVOS-043 — Implement Policy Model

**Dependencies:** DEVOS-011 (organisation/project scoping). **Scope:** The `policies` table and domain entity (`specs/database/poc-database-schema.md` §12.1: `id`, `organisation_id`, nullable `project_id`, `key`, `version`, `status`, `definition` JSONB, `created_by`, `created_at`, `published_at`) within `packages/policy/src/rules/` and `packages/domain/src/policy/` (`specs/architecture/repository-code-structure.md` §11/§17). Note the schema defines a single table with a JSONB `definition` column, not a separate "policy definitions" table. A Policy may apply at organisation, project, workflow, agent, tool, or environment level (`specs/architecture/domain-model.md` §12.1). **Acceptance:** Policies are created in draft, versioned, and published; published policy versions are immutable (`poc-api-contracts.md` §31, schema §12.1), matching the same create/publish/immutability pattern already proven for workflows (DEVOS-013) and agents (DEVOS-025).
