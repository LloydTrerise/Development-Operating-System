# DEVOS-041 — Implement Context Builder

**Dependencies:** DEVOS-039, DEVOS-040. **Scope:** A deterministic context assembler (`packages/knowledge/src/context/`) implementing the Context Assembly pipeline (`specs/architecture/system-context-engineering-knowledge.md` §22): identify task → identify required context → identify applicable policies → retrieve authoritative sources, project context, artifacts, and repository/integration data → apply precedence rules → detect conflicts → validate sufficiency → assemble the execution context. Concrete precedence ordering across context types is explicitly deferred by the spec itself ("A later technical specification should define precedence for individual context types," §18) — this task implements the conceptual ordering (Mandatory Policies > Project Constraints > Approved Requirements > Approved Architecture/Design > Approved Decisions > Current Work Item > Current Repository State > Generated Proposals > Transient Agent Reasoning) as a working default, flagged as an implementation choice rather than a spec-mandated algorithm. **Acceptance:** "The context assembler [is] a deterministic platform capability" (§22) — the agent is not responsible for discovering its own context; source selection, filtering, and size limits are applied before context reaches the agent runtime; the assembled context feeds DEVOS-042's provenance recording.
