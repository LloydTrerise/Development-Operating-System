# DEVOS-040 — Implement Repository/Document Retrieval

**Dependencies:** DEVOS-039. **Scope:** Controlled retrieval of Repository Context — repository structure, source directories, configuration/build/test configuration, relevant source files (`specs/architecture/system-context-engineering-knowledge.md` §10) — and of previously-approved artifacts, through `packages/knowledge/src/retrieval/`. Per §39's explicit deferral list, this must stay a simple, bounded lookup (e.g. direct file/artifact reference resolution) rather than vector search, embeddings, or repository indexing infrastructure, all of which are explicitly out of scope for the POC. **Acceptance:** Given a task and its project, retrieval returns only authorised, relevant sources (never an unbounded copy of the repository); access control is applied at retrieval time, matching direct-resource-access permission checks (`specs/api/poc-api-contracts.md` §27: "Context retrieval must apply the same permission checks as direct resource access").
