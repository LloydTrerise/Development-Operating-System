# DEVOS-049 — Security/Context Tests

**Dependencies:** DEVOS-041/042 (context builder, provenance), DEVOS-043/044 (policy model, evaluator). **Scope:** Automated tests proving the context/security invariants stated across `specs/architecture/system-context-engineering-knowledge.md` §26 (Context and Security) and `specs/workflows/software-change-workflow.md` §26/§29 (Security Model, Context Isolation): only authorised project information is retrieved; sensitive content is excluded unless explicitly permitted; context does not grant tool authority; retrieved instructions cannot override system policy; project context remains isolated between projects (Domain Invariant §37.7). **Acceptance:** Cross-project isolation is demonstrated (a context build for project A cannot surface project B's sources); a prompt-injection-style scenario (retrieved document content containing instruction-like text) is demonstrated not to grant additional tool authority or bypass policy, consistent with Constitution Principle 6 ("Security Is Outside the Model") and Principle 7 ("Controlled External Actions").
