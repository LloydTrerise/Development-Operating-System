# DEVOS-044 — Implement Policy Evaluator

**Dependencies:** DEVOS-043. **Scope:** A deterministic evaluator (`packages/policy/src/evaluator/`, `packages/policy/src/authority/`) that takes a set of applicable published policies plus an evaluation request (actor, action, scope) and returns a decision. No evaluation algorithm or rule language is specified anywhere in the spec corpus; the only stated constraints are "Policy evaluation occurs server-side" (`poc-api-contracts.md` §31) and "Policy evaluation must be deterministic and independent of model output" (`specs/architecture/repository-code-structure.md` §17) — the evaluator's rule-matching design is therefore an implementation choice, to be recorded in the decision log rather than treated as spec-mandated. **Acceptance:** Given the same policies and the same request, the evaluator always returns the same decision; evaluation never depends on or invokes a model; the evaluator is unit-tested against fixtures with no live infrastructure required (matching Principle 6, "Security Is Outside the Model").
