# DEVOS-047 — Add Planning Approval Gate

**Dependencies:** DEVOS-045; Sprint 1's workflow run state machine. **Scope:** Enforce Stage 6 of the software-change workflow, "Human Planning Approval" (`specs/workflows/software-change-workflow.md` §16): after the planning-path agents (discovery → PRD → technical design → implementation plan, Sprint 2) produce their artifacts, the workflow run must not proceed until a human approval is granted. The approval package is discovery findings, PRD, technical design, implementation plan, applicable context/provenance, and validation evidence (§16). The run transitions to the existing `AWAITING_APPROVAL` workflow-level state (§9) rather than a new one. Development must not begin until the configured planning approval is granted (ADR-SCW-002); development itself is out of Sprint 3's scope (Sprint 4), so this task's observable effect is the run reaching and remaining at `AWAITING_APPROVAL` until DEVOS-045's approve/reject API resolves it. **Acceptance:** A run genuinely pauses at `AWAITING_APPROVAL` after planning completes, bound to the exact four artifacts produced; approving the request moves the run to its next legal state; rejecting keeps development from starting and records the rejection reason, consistent with the rejection flow (§16: Planning Approval → Changes Requested → appropriate planning stage → new artifact version → re-approval).
