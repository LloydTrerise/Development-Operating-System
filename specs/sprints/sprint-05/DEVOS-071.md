# DEVOS-071 — Build/Test/Review E2E

**Dependencies:** DEVOS-062 through DEVOS-070 (last task in Sprint 5). **Scope:** "Pass and fail/rework scenarios" (source description) — extends this repository's established real-process E2E pattern (`tests/e2e/planning-path.test.ts`, `tests/e2e/development-path.test.ts`) with the two scenarios the source names explicitly: a straight-through pass path (build and test succeed, review returns `PASS`, release-readiness returns "ready"), and a rework path (review returns `CHANGES_REQUIRED`, a new development cycle is created automatically per DEVOS-067, and that cycle's own eventual `PASS` leads to "ready") — proving the rework loop actually closes, not just that it triggers once. **Acceptance:** a real, automated test (or a small pair of tests) demonstrates both scenarios against real Postgres and real spawned processes, carrying forward Sprint 4's scoping decision unchanged (build/test commands run for real, locally; git/PR operations remain against the fake/local provider and a local repository, no real GitHub API calls).
