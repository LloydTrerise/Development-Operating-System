# DEVOS-063 — Implement Test Adapter

**Dependencies:** DEVOS-062 (build adapter — same design). **Scope:** "Run and record automated tests" (source description). Stage 8 (§18) lists "unit tests; integration tests; contract tests; relevant E2E tests" among validation activities, with the same required evidence fields as DEVOS-062's build adapter. `specs/architecture/repository-code-structure.md` §45 names `test-run.ts`. **Assumption (flagged, same reasoning as DEVOS-062):** a new `test-run` capability, invoked through the Tool Gateway, executes a real, configured shell command via a real child process against the task's real workspace and captures exit code/stdout/stderr — deliberately not distinguishing unit/integration/contract/E2E as separate capabilities, since nothing in the spec corpus requires that granularity and this POC's own repository already runs its full test suite through one `pnpm test` entrypoint per package. **Acceptance:** invoking `test-run` against a real workspace with a real configured command runs it for real and returns its exit code/stdout/stderr as tool output, authorised/audited/idempotent exactly like `build-run`.
