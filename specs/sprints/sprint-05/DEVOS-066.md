# DEVOS-066 — Implement Review Evidence Schema

**Dependencies:** DEVOS-065 (review agent). **Scope:** "Findings, severity and decision" (source description) — this is the artifact-publishing half of DEVOS-065's own agent stage; the source backlog lists "review agent" and "review evidence schema" as two separate line items, but this codebase's established one-task-per-agent-stage pattern (every prior planning-path agent, DEVOS-031–034, publishes its own artifact in the same handler that produces the structured output) means these are naturally implemented together. A new `REVIEW_EVIDENCE` artifact type (free-text `artifactType`, same non-issue as `TEST_EVIDENCE`), published via the standard `runAgentTask`-then-`publishArtifact` pattern Sprints 2–3 already established for judgment-only agent output (not the Tool-Gateway-mediated pattern DEVOS-057/061 use, since a review produces no external mutation). **Acceptance:** after the review agent runs, a `REVIEW_EVIDENCE` artifact exists whose version metadata contains the findings list and the `PASS`/`CHANGES_REQUIRED` decision, retrievable via the existing artifact-version API (`GET /artifacts/:artifactId/versions/:version`).
