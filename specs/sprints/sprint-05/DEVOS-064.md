# DEVOS-064 — Implement Test Evidence Artifact

**Dependencies:** DEVOS-062, DEVOS-063 (build/test adapters). **Scope:** "Structured test results and provenance" (source description) — Stage 8's own output contract (§18): "Test/Validation Evidence artifact," recording "commands executed; results; failures; warnings; environment; relevant revision; timestamp; traceability to the implementation." A new `TEST_EVIDENCE` artifact type — `Artifact.artifactType` is an unconstrained free-text field (`specs/database/poc-database-schema.md` §14 lists it as "PRD/design/plan/etc.," non-exhaustive; the domain type is already a plain `string`), so this needs no schema/union change, exactly matching how `CODE_CHANGE` (DEVOS-057) was added. Published by deterministic platform code after the build/test tool invocations complete — not agent output — mirroring how `run-development-agent-task.ts` assembles the `CODE_CHANGE` artifact's content as a plain object, not a `runAgentTask` call. **Acceptance:** after a real `build-run` and `test-run` complete, a `TEST_EVIDENCE` artifact exists whose version metadata contains both invocations' commands/exit codes/stdout-stderr summaries/timestamps/revision, and references (derives from) the `CODE_CHANGE` artifact it validates.
