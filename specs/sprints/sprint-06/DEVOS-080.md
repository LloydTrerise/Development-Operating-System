# DEVOS-080 — Workflow Timeline Improvements

**Dependencies:** DEVOS-036/060/070 (existing per-run task timeline), DEVOS-079 (full workflow, likely spanning multiple runs). **Scope:** "Complete stage/evidence/decision timeline" (source description, P1) — no wireframe or read-API contract for a cross-run timeline is specified anywhere (the same gap DEVOS-060/070 already found and resolved for their own single-run sections). Sprint 5's own DEVOS-071 explicitly flagged that "no API exposes a work item's runs" — this task is the natural place to close that gap, since a full Stage 1–12 chain (per DEVOS-079) now genuinely spans multiple workflow runs for one work item (planning, development/validation/review, and release), and a per-run timeline alone can no longer show the complete picture. **Acceptance:** a user can see, for a given work item, the complete ordered sequence of stages/evidence/decisions across every run that work item's change went through — not just the single run `RunsPage.tsx` already shows — including release readiness, release approval, deployment, post-release validation, release evidence, and closure once those exist.
