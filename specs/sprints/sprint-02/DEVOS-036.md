# DEVOS-036 — Add Agent Execution UI

**Priority:** P1 (source-stated; the only P1 task in Sprint 2 — all others are P0). **Dependencies:** DEVOS-035, DEVOS-020 (the existing `RunsPage`/run-timeline UI). **Scope:** A web UI panel showing an agent execution's prompt/version, context manifest, status, output, and errors — extending Sprint 1's `RunsPage` task timeline rather than a separate page. **Acceptance:** Viewing a run whose tasks are agent executions shows, per task, which prompt version ran, a summary of its context manifest, its status, and either its structured output or its error — subject to the same "no browser available to this agent" verification limitation documented for DEVOS-007/DEVOS-020, so this task's UI rendering will need the same manual browser check before being trusted.
