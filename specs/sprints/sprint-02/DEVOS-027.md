# DEVOS-027 — Implement LLM Provider Adapter

**Dependencies:** DEVOS-026. **Scope:** A provider-agnostic adapter interface plus one concrete implementation for this project's chosen provider (Google Gemini, free tier — a project decision made when Sprint 2 was scoped, not part of the historical source document). The adapter boundary must not leak Gemini-specific request/response shapes into the agent runtime, so a later provider swap (the source's explicitly named "provider lock-in" risk) only touches this one package. Configuration via `GEMINI_API_KEY`, documented in `.env.example` following the existing `DATABASE_URL`-style convention — never committed with a real value. **Acceptance:** The adapter can make a real call to Gemini and return a normalized response through the interface; a fake/mock implementation exists for unit tests so the rest of the agent runtime never needs live API access to be tested.
