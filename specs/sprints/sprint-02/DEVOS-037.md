# DEVOS-037 — Agent Evaluation Fixtures

**Dependencies:** DEVOS-031, DEVOS-032, DEVOS-033, DEVOS-034. **Scope:** Golden input/output fixtures for each of the four agents, plus regression tests run against those recorded fixtures rather than live LLM calls on every test run — keeping CI fast and safe against the Gemini free tier's rate limits (the same "unit tests against fakes, live calls reserved for deliberate verification" philosophy already established across Sprint 1's test suite). **Acceptance:** Each agent has at least one golden fixture; a regression test suite runs against fixtures in CI without making a live API call, and a documented (manual or scripted) path exists for refreshing a fixture against the real provider when a prompt or schema changes deliberately.
