# DevOS Sprint Task Specifications

This directory contains the version-controlled implementation task authority for DevOS.

## Authority

`sprint-01` was recovered from `Analysis/DevOS_POC_Sprint_1_Implementation_Tasks_v1.0.docx`. Its task IDs, dependencies, scope, and acceptance criteria are authoritative for Sprint 1. The historical product backlog uses a conflicting identifier scheme and is not the task-ID authority.

## Future sprints

Before implementation begins for any future sprint, convert its approved historical task plan into reviewed Markdown files in a corresponding `sprint-XX/` directory. A task may not begin until its Markdown specification is present and its dependencies are recorded as complete or explicitly deferred.

## Status convention

- **COMPLETE** — source and acceptance criteria demonstrably satisfied.
- **PARTIAL** — some scope exists, but acceptance criteria remain unmet.
- **NEXT** — approved next task to plan/implement.
- **FUTURE** — planned but not started.
