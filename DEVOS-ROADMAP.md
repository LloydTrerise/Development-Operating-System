## Authority

Sprint task specifications under `specs/sprints/` are the authority for task-level IDs, scope, dependencies, and acceptance criteria. Every sprint from Sprint 1 through the current position below has its own reviewed `specs/sprints/sprint-NN/` folder (a `README.md` plus one file per task), converted from its own source backlog document before that sprint began — Sprint 1 from its historical developer-ready task specification, Sprints 2–8 from their respective `Analysis/DevOS_POC_Sprint_N_Implementation_Tasks_v1.0.docx` documents, and every sprint since from the epic backlog document (`specs/DEVOS-*-BACKLOG.md`) that scoped it — per `AGENTS.md` §35's requirement that a future sprint's task plan be converted into reviewed Markdown before that sprint begins. See the Delivery roadmap table below for which backlog document scoped which sprint, and `DEVOS-BUILD-STATE.md`'s own condensed state-change log for a one-line, dated index of every sprint's real completion evidence.
